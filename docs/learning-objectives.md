# Objectifs

À la fin de ce premier palier, on sait :

1. Relever le système, le noyau, GCC et GDB avec des commandes qu'on peut relancer.
2. Configurer un dépôt Git dont l'historique se lit commit par commit.
3. Compiler un programme C17 en traitant les avertissements comme des erreurs.
4. Lire le nom du système, le noyau, l'architecture, la taille de page et le nombre de processeurs en ligne.
5. Comparer cette sortie à `uname` et `getconf`, et échouer avec un code de sortie si la lecture ou l'écriture rate.

Les objectifs d'après (fichiers, options) sont dans `ROADMAP.md`. Ils ne sont pas exigés ici.
